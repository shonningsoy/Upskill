# Glossary

Add short definitions here when a term appears across several Snowflake, dbt, or Fivetran topics.

## Terms

- **Warehouse**: Snowflake compute resource used to execute queries and DML.
- **Database**: Logical container for schemas.
- **Schema**: Logical container for tables, views, stages, procedures, and other objects.
- **Role**: Security principal used to grant privileges.
- **Credit**: Snowflake unit of compute consumption.
- **ELT**: Extract, load, transform; common modern data stack pattern.
- **CDC**: Change data capture; detecting and processing changes from source systems.
